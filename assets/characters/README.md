# assets/characters/

Buraya eklenen görseller giriş ekranındaki arka plan kolajında ve karakter
kartlarında otomatik olarak belirir — kod değişikliği gerekmez. Dosya yoksa
o görsel sessizce atlanır (hata göstermez).

## Beklenen dosya adları

Kolaj (arka plan, yavaş kayan katmanlar — istenen sayıda, 1'den başlar,
boşluksuz artmalı):

- `collage-1.webp`, `collage-2.webp`, `collage-3.webp`, …

Karakter portreleri (giriş ekranı kartları ve ileride diğer yerler için):

- `archon.webp`
- `multivac.webp`
- `mirror.webp`

## Format

- Yalnızca `.webp`.
- Kolaj görselleri: dikey/portre oranı, yüksek çözünürlük gerekmez (arka
  planda blur + vignette ile gösterilir).
- Dosya adı tam olarak yukarıdaki gibi olmalı (küçük harf, tire).
